**五条铁律**：
1. 服务器连不上境外网络——代码本机打包中转，镜像/模块走国内源。
2. 所有 tar/scp 源目录必须是 `_local`（官方克隆没有补丁）。
3. 服务器 `runtime/` 是现场配置，tar 必排除。
4. 源码改动一律提交 `patches` 分支并 `git push mine patches --force-with-lease`。
5. **服务器零编译**：服务端二进制一律**本地交叉编译**后上传持久化目录（见《源码更新手册》§4.2）；首次建镜像除外。

**Shell 铁律**：含 heredoc（`<<'PY'`）或多行 python 的命令**不要**从本机 PowerShell 用 ssh 转发（多层引号必炸）——写到本机 `.sh` 再 `scp` 上去执行。

## 4. ServerS5A3 首次部署

> 首次需建一次 Docker 镜像（含基础运行环境）。**日常更新走《源码更新手册》§4.2 本地编译+持久化目录，不在服务器编译。**

### 4.1 上传源码与 PVF
```powershell
cd F:\90cn\轻装上阵\deploy
tar -czf ServerS5A3.tgz --exclude ".git" -C _local ServerS5A3
scp ServerS5A3.tgz root@124.221.247.221:/srv/apps/
scp "F:\90cn\轻装上阵\client\Script.pvf" root@124.221.247.221:/srv/dnf-assets/Script.pvf
ssh root@124.221.247.221 "cd /srv/apps && tar -xzf ServerS5A3.tgz && rm -f ServerS5A3.tgz && sha256sum /srv/dnf-assets/Script.pvf"
Remove-Item ServerS5A3.tgz
```

### 4.2 首次构建镜像（仅首次 / 改 Dockerfile 时）
```bash
cd /srv/apps/ServerS5A3
export GOPROXY=https://goproxy.cn,direct
docker build --memory=4g --memory-swap=6g -t servers5a3-local:dev -f deploy/docker/Dockerfile .
docker tag servers5a3-local:dev servers5a3-local:pre-init   # 回滚保险
```
> **只跑 docker build 一步**——Dockerfile 多阶段已在容器内编译 DNF90Server/Assets。切勿再跑 `build.sh`（宿主机额外编译 3 个二进制），两轮背靠背 go build 曾把 4C/7G 打满、SSH 无响应。内存上限 `--memory=4g` 防止 OOM。

### 4.3 初始化 + 启动（120 频道基线）
```bash
cd /srv/apps/ServerS5A3
python3.12 deploy/docker/manage.py prepare --channel-info go-server/internal/services/dnfbridge/testdata/channel_info.etc
cd runtime/docker && sed -i s/124.221.247.221/10.253.90.2/ instance.json   # up 要求私网
cd /srv/apps/ServerS5A3
python3.12 deploy/docker/manage.py up --host-ip 10.0.0.14 --channel-info go-server/internal/services/dnfbridge/testdata/channel_info.etc
```
> `--channel-info` 必须显式给 120 频道基线（sha `5630b099…`），CSV 不行；旧自定义表须先 `mv` 出 `data/` 目录（同目录改 `.bak` 不算）。`--host-ip` 必须 RFC1918 私网地址。up 成功输出 `Prepared 120 real channels`。

### 4.4 `instance.json` 推荐预设（一次性）
编辑 `/srv/apps/ServerS5A3/runtime/docker/instance.json`（不在 git 内），合并模板 `deploy/templates/docker-instance.recommended.json`：**只加键、不覆盖** `database_ip/password` 等连接类配置。要点：`runtime_compatibility` 23 项、顶层 `buff_group_sync`/`buff_swap_reapply`/`disjoint_epic_display`/`town_display_only`、公会 5 项、`performance_profile: shared-4c-16g`；另设 `channel_advertise_server: 1`（必须与登录器 profile 的 `ChannelServerId` 一致）、`dungeon_tournament: vendor`、生成 `player_proxy_secret`。改完重跑 §4.3 的 up。

### 4.5 post-fix（每次 up 后必做）
写成 `.sh` 上传执行（避免多层引号）：
```bash
cd /srv/apps/ServerS5A3/runtime/docker
sed -i 's/^DNFBRIDGE_SERVER_IP=.*/DNFBRIDGE_SERVER_IP=124.221.247.221/' server.env
sed -i 's/"server_ip": "10.253.90.2"/"server_ip": "124.221.247.221"/' instance.json
python3 -c "import json; P='compose.json'; d=json.load(open(P)); d['services']['db'].setdefault('ports',['127.0.0.1:3307:3306']); json.dump(d,open(P,'w'),indent=1)"
# 写回 admin secret：从 gateway.json 的 management.gameToken 取（up 会覆盖成空）
python3 - <<'PY'
import json
g = json.load(open('/srv/apps/PurpleMagic/runtime/selfhost/gateway.json', encoding='utf-8'))
token = g['management']['gameToken']
p = 'server.env'
lines = open(p, encoding='utf-8').read().splitlines()
out, found = [], False
for line in lines:
    if line.startswith('DNFBRIDGE_PLAYER_ADMIN_SECRET='):
        out.append('DNFBRIDGE_PLAYER_ADMIN_SECRET=' + token); found = True
    else:
        out.append(line)
if not found: out.append('DNFBRIDGE_PLAYER_ADMIN_SECRET=' + token)
open(p, 'w', encoding='utf-8').write('\n'.join(out) + '\n')
PY
docker compose -p servers5a3-local -f compose.json up -d --force-recreate server
docker inspect servers5a3-local-server-1 --format '{{.State.StartedAt}}'   # 必须晚于本次操作
```
> 作用：SERVER_IP 改回公网（up 写内网）、补 db 3307 映射（up 会丢）、补 admin secret（up 会清，否则 admin API 全 404）、`--force-recreate` 让 env 生效（`restart` 不重读）。`-p servers5a3-local` 不能省。

### 4.6 首次部署后：切到本地编译二进制（推荐）
首次部署用的是镜像内二进制。按《源码更新手册》§4.2 把服务器二进制切换为本地编译版（持久化目录 + entrypoint），以后换版零编译、秒级回滚。

### 4.7 验证
```bash
docker compose -p servers5a3-local ps                       # db/server 均 healthy
ss -tlnp | grep -E ':(7001|17002|18111|3307)\b'
docker logs servers5a3-local-server-1 --since 3m 2>&1 | grep -ciE 'panic|fatal'   # 0
```
> ⚠ **假成功**：up 卡住或退出码被管道吞掉时，旧容器仍 healthy、文件全绿但进程持旧代码。永远核对 `StartedAt` 与日志 `dnfbridge started` 时间。

## 7. 登录器首次编译与交付

### 7.1 工具链（一次性）
- .NET 8 SDK：`winget install Microsoft.DotNet.SDK.8`；VS Build Tools（VC.Tools.x86.x64）；Windows SDK 缺时**管理员权限**补装 `Microsoft.VisualStudio.Component.Windows11SDK.26100`（非提权会 exit 0 假成功）。

## 10. 部署期坑速查

| 现象 | 解法 |
|---|---|
| 远程写文件后 `ls` 都没有 / PATH 坏 | PowerShell 吞 `$PATH`，用 `` `$ `` 或 base64 |
| VS 静默装 SDK 假成功（exit 0 没装） | 管理员提权或 `winget install Microsoft.WindowsSDK.10.0.26100` |
| `Prepare as the non-root deployment user` | `prepare.py --uid 10001 --gid 10001` |
| Probe `Unexpected channel directory identity` | instance.json 的 `channel_advertise_server` = profile 的 `ChannelServerId` |
| Flutter C1083 找不到 `cpp_client_wrapper\*.cc` | §7.2 ①；引擎 release 目录缺 wrapper 时先拷 `windows-x64` → `windows-x64-release` |
| `INSTALL.vcxproj cannot find native_assets` | 删 `launcher\Flutter\.dart_tool\flutter_build` 后重跑 |
| 构建打满 4C 致 SSH 握手超时 | 等 5-10 分钟自愈；腾讯云 WebShell 可进（不走 SSH）；**根本避免：服务器零编译，走《源码更新手册》§4.2** |
| 网关 `management receipt schema unavailable` 重启循环 | 一次性容器跑 `-init-management-schema`（《源码更新手册》§5） |
| 服务器硬重启后全服不可用 | servers5a3 db/server 不自启：先 `docker compose -p servers5a3-local -f runtime/docker/compose.json start db` 再 `start server`；缺库时 gateway 会 `management database unavailable` 无限重启（load 很低，别误判死循环） |
